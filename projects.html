Nutritional Analysis using Computer Vision

A computer vision project that detects food and dairy products from images and webcam input and retrieves their nutritional information from a structured dataset.

The project uses YOLO-based object detection through Roboflow, OpenCV for image and webcam processing, and Pandas for nutritional data lookup.

Python OpenCV YOLO Roboflow Pandas
  • Image-based food/product detection
  • Real-time webcam detection
  • Nutritional information lookup
  • Bounding-box visualization
  • Aggregation of nutritional values
